منصة العلم نور — ENG ELMAZAHY\n\nواجهة بداية عربية لطلاب البكالوريا المصرية بإشراف مستر يوسف شريف.\n\nللتشغيل: npm install ثم انسخ .env.example إلى .env وأضف بيانات مشروع Supabase، ثم npm run dev.\n\nقاعدة البيانات: أنشئ مشروع Supabase وشغّل supabase/schema.sql في SQL Editor.\n\nتنبيه: هذه حزمة بناء أولية وليست منصة منشورة أو مكتملة الإنتاج. يلزم استكمال لوحة المدرس، صلاحيات الإدارة الآمنة، حفظ المحاولات والتصحيح من الخادم، وربط التخزين للفيديوهات والملفات قبل استقبال الطلاب. لا تضع مفتاح الخدمة السري في الواجهة.
